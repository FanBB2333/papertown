# 方法草案模板

| 栏目 | 写什么 |
| --- | --- |
| title | 英文题目，体现问题和核心机制 |
| problem | 问题定义：输入、输出、要优化的目标；一段话 |
| mechanism | 2～4 条核心机制，每条对应撞车报告里的一个空白点 |
| baselines | 对比对象：`name` 和 `source`（仓库路径或 arXiv id） |
| datasets | 评测用的任务或数据集 |
| metrics | 评价指标，沿用已有定义 |
| risks | 可能失败的地方，以及失败时退回哪一步 |

## 好草案的标准

- 机制和空白点一一对应，审稿人能看出"为什么之前没人这样做"。
- baseline 里至少有一个是最相近的已有工作。
- 指标能直接从评测脚本里算出来。
